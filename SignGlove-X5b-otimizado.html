Como abrir no celular
  1. Use um navegador atualizado e abra esta página fora da prévia do chat.
  2. Toque em Iniciar câmera e permita o acesso.
  3. Se o arquivo baixado não liberar a câmera, esta página precisa ser disponibilizada em um endereço HTTPS. Ela funciona em hospedagem estática, sem servidor Python.

Abrir HTML pelo gerenciador de arquivos do Android pode limitar as permissões. O botão Testar uma foto permite escolher uma imagem quando disponível. Não é um APK.

Para desenvolvimento local, use localhost. Abrir pelo IP de outro computador em HTTP não é suficiente para liberar a câmera.

Dicas e limites do protótipo

Modo leve para celular: a versão publicada usa captura de até 480×360, análise em baixa frequência e ajuste automático conforme o tempo de processamento. Isso reduz a carga do processador em aparelhos de entrada.

Use boa iluminação, mantenha todos os dedos no quadro e teste diferentes distâncias. Para repetir a mesma letra, retire a mão do quadro e mostre novamente.

O modelo original reconhece apenas A, B, C, D e F. Pode confundir sinais desconhecidos com essas letras; a confiança exibida não comprova acerto. Não é um tradutor completo de Libras.

O classificador foi convertido do projeto original. O detector pode localizar até duas mãos; para reconhecimento, este modelo classifica a mão de maior área. O detector de mãos foi adaptado para a versão Web do MediaPipe; a precisão em câmeras de celulares ainda precisa de avaliação.

Internet e privacidade

Esta versão precisa de internet para baixar o detector do Google e o código do MediaPipe via jsDelivr. Não há garantia de funcionamento offline.

O aplicativo processa as imagens no próprio navegador e não contém envio de fotos ou vídeo. A câmera é desligada ao pausar ou sair da página. O texto não é salvo automaticamente.
